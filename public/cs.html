The read

  1. The typical direct copilot is a few hundred to a few thousand Chrome users. That is not a breakout category.
  2. eesel’s live customer-service extension has 5,000 users. Forethought Assist has 6,000. Tidio’s copilot has 579.
  3. Only one direct listing is even on the 10,000-user weekly file: eesel’s old docs search. It did not grow this week or this month.
  4. Hiver is the closest large customer-service listing (50,000 users). Flat this week. Down 10,000 users this month (−17%).
  5. Glean, Text Blaze, and Magical added users this month. Those are company search and text shortcuts, not ticket copilots.
  6. If we build this, the bet is paid-product demand, not Chrome-store demand. The store channel looks quiet.

The real product

AI that writes helpdesk replies. These are small. Almost none show week growth because they never hit 10,000 Chrome users.
