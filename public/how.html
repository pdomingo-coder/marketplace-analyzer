How we built it

  • Chrome

    Your ranking CSV is streamed into a local database. We keep name, users, stars, type, and a short blurb. We do not paste the dump into chat.

  • Jira

    The official Marketplace list. Installs, stars, and type. No third-party scrape. We freeze today’s install counts on this Mac so you can compare growth after you ingest again.

  • Jobs

    We match words in the name and blurb to jobs people pay for. “Acrobat” and “PDF” land in PDF. “LastPass” lands in passwords.

  • Notes

    On click, we read public reviews for a few busy apps. AI groups the asks. Quotes stay from the store. If AI is off, we fall back to word match. Stars already show mood.

Quick questions

Where does the data live?

On this computer, in a local file. The app runs at 127.0.0.1. It is not on the public web.

Why is a box empty?

That filter has no matches. Example: you already zoomed into one type, so “weak types” has nowhere else to point. The list below still has the apps.

What does Gap mean?

Busy product, lots of notes, not-great stars. A place a cleaner product could win.

Are the user counts guesses?

No. Chrome uses the ranking file. Jira uses Atlassian’s install count.

How does Jira week growth work?

Atlassian does not publish last week’s installs. We save a local snapshot, then compare after you run ingest:jira again.

What is the Week growth page?

A second Chrome file with week / month / 3-month user change, for extensions at 10k+ users. We join it to the Aug 25 dump for type and listing URL. Sort by week % to find new apps that jumped.

Does AI make up comments?

No. It only groups notes from the store. Each card keeps a real quote. If AI is down, we fall back to word match.
